# Product Page layout rules

Use the pack as a starting hierarchy, not a fixed page template. The feature hero owns
the first primary action. Supporting sections may be reordered only when the feature
contract records the reason. A temporary interactive demo may live inside the hero or
in the next section when PM selects a hybrid composition.

## Decision basis

The marketing story and product interaction must remain distinguishable so a manager
can review both without mistaking temporary UI for final design.
