# PM temporary assets

This feature uses the PM-supplied files below for deterministic prototype review:

- `sample-video.mp4`: local source and result-video stand-in.
- `sample image.jpg`: local portrait thumbnail and canvas poster.

Both files are temporary PM media. They may be used for PM review and design-working
prototypes, but a design-final revision must replace or explicitly approve them through
the Shared Design Library.
