# Prototype Factory Readiness

## Goal

Prove that the new factory can render a React prototype from PM-owned inputs without
Designer involvement or backend access.

## User

The project PM preparing a manager-review prototype.

## Required behaviour

1. The page clearly identifies itself as a mock-data prototype.
2. It shows that the PM contract, token baseline and mock data are present.
3. The user can move the demonstration from draft to review-ready state.
4. The user can reset it to draft.
5. No action calls a backend.

## Out of scope

- Product feature design
- Final Figma
- Real customer data
- API or authentication
