# Brand voice（draft for PM review）

## Tone

- Direct and practical: say what the user can do, then how.
- Confident without hype: no "revolutionary", "magic", "best in the world".
- Second person ("you", "your photo"); present tense.
- Short sentences. One idea per sentence. Headlines under 8 words where possible.

## Vocabulary

- Product name exactly as in `product.yaml.name`; a shorter display name (e.g. "AI Character Motion Swap") only if the PM spec lists it as an approved alias.
- "photo", "video", "clip", "character", "reference video", "generate", "download in HD", "My Gallery".
- Avoid "upload your face", "deepfake", "real person" unless the PM spec says so.

## Structure

- Hero: value in one line + one primary action.
- Intro: restate the value with the input/output ("upload a photo and a video → your character moves").
- Benefits: 3 to 4 bullets with a bold lead-in.
- How to: numbered steps that mirror the actual tool UI order from the feature spec.
- Use cases: one paragraph each, ending with the audience or platform it serves.
- FAQ: answer first, then the condition.
